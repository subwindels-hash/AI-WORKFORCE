## Summary

### Lead Discovery (primary feature)
- **Apollo.io provider** wired end-to-end (class, ApiProviders driver + health probe, controller registry, UI selector, env docs, 8 unit tests).
- **Business Mode** — keyword array + country + city targeting (e.g. Banking, Commercial Real Estate, Architecture in Lagos, Nigeria). Works with Google Places and Apollo.
- **Person Mode** — first-name list + country + city; server-side filtered to free webmail domains (`icloud.com`, `gmail.com`, `yahoo.com`, `outlook.com`, plus `hotmail.com`, `aol.com`, `proton.me`, `live.com`, `me.com`, `mail.com`, `gmx.com`, `yandex.com`). Apollo required.
- **Honest per-lead verification** — `verified` / `partial_verified` / `business_listing` / `provider_enriched` pills driven by Apollo `email_status` and direct-phone presence (no blanket "100% verified" claim).
- **In-platform cold outreach** — `POST /leads/:id/outreach` supports `email`, `linkedin`, `note`, `call`; inserts into `lead_outreach`, flips status to `contacted`, logs `OUTREACH_SENT`. Email delivers via Resend (`RESEND_API_KEY`) → Postmark (`POSTMARK_SERVER_TOKEN`) → SMTP (`SMTP_*`) when configured; otherwise saved as a draft. Sender identity from `OUTREACH_FROM_EMAIL`/`OUTREACH_FROM_NAME`.
- New `GET /modes` endpoint; leads rows now populate `lead_kind`, `email`, `job_title`, `company_name`, `linkedin_url`.
- UI: mode tabs, keyword/city/country inputs, name-list textarea, free-email domain chips, Outreach button per result and per pipeline card, verification/kind pills, Persons + Verified stats.

### Additional completed modules
- **Lottery / EuroMillions dashboard** at `/lottery` with RBAC gating.
- **Per-user broker connections** — AES-256-CBC + HMAC token encryption in `user_broker_connections` (added to MySQL + SQLite schemas and `SchemaInstaller` idempotent upgrades); UI at `/brokers/connect`.
- **Broker adapters** added: Alpaca, Bybit, Coinbase, Kraken, Oanda, OKX, IBKR.
- **Admin inbox + email templates** (schema, `EmailTemplates.php`, views, controller methods).

### Fixes
- Fixed escaped-quote bug in `SchemaInstaller::ensure()` SQLite `sqlite_master` query.
- Added `user_broker_connections` to `SchemaInstaller::EXPECTED_TABLES` and `upgrade()`.
- Apollo metadata now retains `email_status` so verification signal survives normalization.
- Person-mode `first_names` forwarded into Apollo `q_keywords`.

### Tests
`tests/cases/79`–`85` cover crypto exchange providers, broker providers, user-broker connections, Apollo provider, and the new modes+outreach wiring.

### Docs
`docs/LEAD_DISCOVERY.md` updated for Modes, verification semantics, outreach transports; `.env.example` updated for Apollo + outreach envs.
